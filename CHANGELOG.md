# Changelog

All notable changes to RuinDial are documented here.

## 1.0.0 - Unreleased

### Added

- Four destruction characters and eight factory programs
- Input/output trims, dry/wet mix, bypass, A/B snapshots, and randomization
- Raw, 2x, and 4x quality modes with latency compensation
- Resizable professional interface with output metering
- Cross-platform CI, DSP tests, release packaging, signing, and notarization hooks
- Manual, compatibility matrix, release guide, and uninstall script

### Changed

- Destroy now starts at a transparent, level-safe default
- Output is protected by a soft limiting stage

## 0.1.0 - 2026-05-24

- Initial AU, VST3, and standalone implementation
- One-knob destruction engine and custom editor
